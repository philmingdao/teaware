# Museum display environment

`museum-vitrine.webp` is a generated, illustrative museum environment, shared by
the slideshow and TV display. It is not a photograph of any source museum's
actual installation. Created with the built-in `image_gen` tool on 2026-10-03,
then encoded as WebP for the static website. Source exhibit photographs retain
their original color and pattern; only their existing transparent silhouettes
are composited over the scene. No generated artefact replaces a collection image.
