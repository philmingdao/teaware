# 茶器收录范围清理

用户要求版画、书页、织物以及其他非茶器从全库删除，未来不再收录。采用明确茶用依据的收录边界：藏品必须是实际茶器或专门茶事用具；绘画、版画、摄影作品、出版物页面即使描绘茶器也不符合范围。古陶器、酒器、花瓶、陈设及普通碗杯不能因为材质、窑口、搜索结果或自动生成的“茶器”标签获得准入。

清理前 11,456 条，清理后 1,428 条。移出 4,581 条明确超出范围的记录；另将 5,431 条缺少明确茶用依据的记录移出当前展览。这一部分的审计原因是 `tea-use-unverified`，不将“缺少证据”等同于“已证明不是茶器”。未来取得来源依据后，需要明确复核排除记录才能重新收录。

`research/teaware-exclusions.json` 保留每个移出 ID、馆方名称、材质、出处 URL、原图 SHA-256 和原因。完整清理前元数据保存在忽略的 `output/collection-curation/`；历史原图可通过 Git LFS 历史恢复。当前网站的两份活动目录同步清理；移出条目的规范原图及已发布的封面/试展副本一起移除。旧的活动目录备份也迁出源代码目录。

## 判定规则和核验

- 依据 `titleEnglish`、来源材质/器物名称及 Commons 原始文件名；不以自动生成的中文名称或通用 `Tea Bowl/Cup` 类型为茶用证据。
- 来源中的 tea bowl、teapot、tea caddy、茶碗、茶入、水指、theepot 等明确器物名称可准入。材质中的 albumen silver print 是摄影介质，不因 silver 被当成银茶器。
- 茶器上的抽象卷草纹、纹章、剪纸贴花和转印装饰不等于书画或织物。相关误判场景有针对性测试。
- `cma-128457` 唐代银高足杯的[馆方说明](https://www.clevelandart.org/art/1951.396)明确这类器物用于茶与酒，保留，并如实表述兼用用途。
- `cma-76525` 白釉玉璧底碗的[馆方说明](https://www.clevelandart.org/art/2020.186)明确这类形制用于饮茶，保留；修正旧中文记录中错误的唐代及陶器标签。
- 封面中的普通钧窑碗、杯与盏托、梅花杯未取得明确茶用依据，替换为已经核对 Mia 元数据的耀州窑刻莲纹茶碗、宜兴束竹式茶壶、吉州窑剪纸贴花茶盏，标题/说明/图片使用相同 ID。
- 展柜反射属于图像质量问题。若本体确为茶器，修复背景蒙版；若本体用途未核实，不以误生成的茶器标签保留。`wiki-3217332` 为未核实的新石器陶罐，移出；`wiki-23259848` 墓志铭、`wiki-89869791` 版画均移出。

## 防止再次收录

`scripts/teaware-policy.mjs` 是统一准入规则。主导入器应用该规则；`npm run build` 首先运行 `scripts/verify-teaware.mjs`，同时检查目录一致、茶用依据、排除 ID/来源 URL 以及封面/试展引用。旧爬虫即使绕过新导入器，污染目录也不能构建发布。图片清单生成、批处理和透明图发布同样使用这一边界。

不为追求数量恢复宽泛的 ceramic/bowl/cup/wine 搜索准入，也不保留页面中的非茶器照片。图片处理继续以清理后的活动目录为输入。

逐图复核又移除了 `colbase-kyohaku-I甲270`（茶筅纹样织物）及 `colbase-tnm-QA-3113`（茶入分类记录册），两者旧类型均误标成茶器。规则补充了对应日文非器物名称，另移除 3 张 V&A 书页及 1 张织物主图、1 张印刷插图。移出总数 10,028，其中 16 张为不适合作主图的整柜、整架及局部特写照片，而不是断言相应器物不属于茶器。

透明图复核后，活动库 1,428 件全部通过发布门槛。17 张荷兰国立博物馆乳白玻璃茶杯换用馆方 IIIF 原生高清裁切，修正中文材质误写；出处、权利和哈希见 `collection-image-refreshes.json`。逐图审批见 `collection-cutout-review.json`。
