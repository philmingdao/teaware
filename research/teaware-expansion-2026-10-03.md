# 茶器资源扩充至 2,000 件

从原有 1,428 条记录出发，合并 41 条重复记录，移除 1 条茶用途未获馆方证实的旧记录，保留 1,386 件并新增 614 件，最终为 2,000 件。馆方分别登记的不同器物仍保留独立记录；同一藏品的重复来源和同一组装茶罐的壶身／盖重复照片不重复计数。

| 新增来源 | 件数 |
| --- | ---: |
| 明尼阿波利斯艺术博物馆 | 190 |
| 大都会艺术博物馆 | 177 |
| 荷兰国立博物馆 | 111 |
| 库珀休伊特史密森尼设计博物馆 | 100 |
| 史密森尼美国历史博物馆 | 26 |
| 沃尔特斯艺术博物馆 | 10 |
| 合计 | 614 |

收录以馆方明确的茶用途和实际器物照片为依据。新增图片仅采用明确开放许可的馆方原图；沃尔特斯图片采用与官方登记号精确匹配的开放共享资源镜像。保留馆方原文器名、年代、材质、编号和来源链接；中文器名按真实器型和主要材质整理，未知字段不推测。史密森尼的馆藏编号使用独立物件 ID／catalog number，不以同批捐赠的 accession number 代替物件身份。

排除版画、书页、纯织物、窑址废料与孤立残片、带标签／反射残留的展柜照片，以及将整组餐具标题套用于单独咖啡壶或糕点架的错误候选。新增候选共 849 条；原图和透明候选在九批对照页中逐件检查，641 件获得视觉通过，进一步排除低清候选并留出备用项后采用 614 件。去重映射、每件来源、许可、原图哈希、透明图哈希与复核页见同名 JSON 审计文件。

图片沿用本地 BiRefNet full 模型和 Apple MPS：只分割透明蒙版，保留原图颜色和纹样；无原图放大，输出 1,200 像素透明 WebP，透明通道无损。已通过逐图轮廓检查和全量原图／候选哈希、透明边界、尺寸及编码保真检查。封面、列表、详情、幻灯和电视模式均通过同一透明资源清单取图；平面茶匙／茶滤不添加站立器物的地面投影。

最终清单为 2,000 个已复核映射、1,992 个透明文件，约 128 MiB。少量既有的馆方独立登记器物共用馆方组合照片。静态发布包只包含当前清单中的透明资源，归档原图不进入 GitHub Pages。

验证：茶器收录边界与去重检查通过，六组收录规则测试通过，修改脚本的 ESLint 检查通过，Next.js 静态构建及全量透明资源打包通过。仓库全量 lint 仍包含旧脚本、现有 React effect 代码和本地输出目录中的既有问题，本次没有修改这些文件。
